# MixCentral Stock

Sistema web de gestão de estoque para o Supermercado Mix Central: controle de entradas, saídas, lotes e validade, alertas e relatórios.

Projeto prático da disciplina de Desenvolvimento Web (Prof. Esp. Welliton Cunha).

| Integrante | Papéis |
| --- | --- |
| Arylson Simão Lopes | Coordenação, Backend, Banco de Dados |
| Davy Lopes da Cruz | Frontend, UX/UI, Documentação |

## Tecnologias

- Frontend: React (Vite) e Bootstrap
- Backend: Node.js com Express
- Banco de dados: PostgreSQL
- Prototipação: Figma
- Controle de versão: Git e GitHub

## Estrutura

- `frontend/`: interface web
- `backend/`: API REST
- `docs/`: documentação do projeto
